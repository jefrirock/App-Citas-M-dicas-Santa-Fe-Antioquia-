App Citas Médicas
Aplicación para la gestión y agendamiento de citas médicas de la ESE Hospital San Juan de Dios de Santa Fe de Antioquia.
Funcionalidades
 • Agenda de citas médicas por especialidad
 • Visualización de próximas citas
 • Consulta de resultados médicos
 • Gestión de perfil de usuario
 • Interfaz responsiva (móvil y web)
Tecnologías
 • Lenguaje: Dart
 • Framework: Flutter
 • Backend: Firebase (Cloud Firestore, Autenticación)
 • Plataformas: Android, iOS y Web
